03 / 11   Our answer

The agent never holds a key

The agent runs in a locked container with no credential and one route out. The broker holds every key and asks a coded policy engine before anything reaches Vultr.

The engine answers ALLOW, ESCALATE or DENY and names the rule that decided.

ALLOW
ALLOWinside the agent's authority, so the broker runs it
ESCALATE
ESCALATEheld until a person approves it
DENY
DENYdoes nothing and names the rule
No key in the sandbox · one route out · keys only in the broker · code decides, not the model

04 / 11   How a request flows

One request, start to finish

Every action is a single request to the broker. The policy engine and the spend meter decide first, and only an ALLOW reaches your Vultr account. Each decision is written to an append-only ledger.
