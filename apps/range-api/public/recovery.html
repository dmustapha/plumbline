In plain words: recovery has two parts. Object Storage keeps old versions, so a deleted object can be brought back; that is the one live undo, and a deleted server cannot be restored. For actions that cannot be undone, each session has a small dollar bond: an approved irreversible delete burns some of it, and while it is low, new servers are refused.
