Stated limits

  • Point-in-time: a resource created and destroyed between two polls is not seen. A destroy is visible within about 0.8 s, so a rogue VM is declared only when it is present at both polls.
  • The ledger is the broker's own record. The verifier checks its hash chain, its freshness and that it only ever grows; a broker that lies consistently from its first row is caught only by the live comparison and the policy re-run.
  • Not covered with a view-only key: firewall groups (403), Object Storage buckets (403), dollar ceiling and session spend. Covered: instances, VPCs, container registries.
