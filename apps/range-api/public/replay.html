Do not trust this page: check the ledger yourself

A page can show anything, so this one lets you check it. The whole ledger is public. Each row carries a fingerprint (a SHA-256 hash) of its own contents plus the fingerprint of the row before it, so changing any past row breaks every row after it. The button below downloads the ledger and recomputes every fingerprint in your browser, with no help from our server. It then compares the result with the position the independent verifier in the second region pinned earlier.

Download the ledger (JSON)
Check it without this page, on your own computer 
curl -s https://plumbline.108-61-70-169.sslip.io/api/ledger/public -o ledger.json
node scripts/verify-ledger.mjs ledger.json

The script is in the public repository, has no dependencies and prints one line per check.

What this proves, and what it does not

Proves: no row was edited, removed or reordered after it was written, every server the agent created is tied to an ALLOW decision, and each recorded request matches the fingerprint the verdict was made on. Does not prove by itself: that the broker recorded every action truthfully in the first place, because the ledger is the broker's own record. That gap is closed from outside: the verifier in the second region reads the live Vultr account with its own key and compares it with this ledger (see Reconcile), and it pins the head of this chain so a rewrite of history is caught.
