What this release is, and is not

It is

  • A working reference implementation: engine, broker, sandbox, verifier, watchdog and ledger on real Vultr infrastructure.
  • A live demo account you can attack, so you can see the verdicts and the reconcile for yourself.
  • Software you can run on your own account, and an audit command that works on any account.

It is not

  • A hosted team product: there is no web setup, approval inbox, alerting or spend history yet.
  • A claim that the model resists attacks, that the sandbox is a microVM, or that create-then-delete is prevented.
  • A multi-cloud tool: only Vultr has an adapter.

The full list of claims and non-claims is on the Safety model.
